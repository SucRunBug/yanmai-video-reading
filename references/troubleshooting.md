# 失败时先定位层，再换路径

| 现象 | 如何判断 | 下一步与停止条件 |
| --- | --- | --- |
| 网页工具报错、空页 | 尚未取得正文或媒体；不能判断视频失效 | 用可用浏览器打开同一目标，或小红书公开手机分享页 |
| 浏览器导航超时 | 导航可能已经发生 | 查询当前 URL / 状态，再核对 ID；工具重置后按当前工具的首次调用规则重新绑定 |
| 标题、作者或 ID 不对应 | 当前页面可能是推荐或跳转后的其他内容 | 停止该对象分析，回原分享链接；不拿其他视频补齐原视频 |
| `unsupported asset kinds` | 资源观察成功，但打包不支持该类型 | 取实际观察到的媒体地址，使用受支持下载方式 |
| 没有媒体请求 | 可能未播放、列表过旧、能力不足 | 播放同一目标并刷新观察；改用其他可用网络观察能力 |
| 下载内容是 HTML / 403 | 返回错误页、签名过期或请求条件不符 | 核对 UA / Referer；重新取同一目标的新地址，有限重试 |
| 下载视频无声 | 静音原片或音视频分轨 | ffprobe 检查；有独立音轨时显式合并，检查时长与同步 |
| `127.0.0.1:<port>` 连接失败 | 可能是沙箱禁止网络，也可能代理没启动 | 先核对执行环境权限及当前代理；必要时走正常联网授权，不直接替换全局代理 |
| HTTPS 验证失败 | Python 信任库或代理证书问题 | 使用当前系统信任链 / 合法 CA 配置，保持 TLS 验证；不使用 `verify=False` 或 `curl -k` |
| Python 包离线解析失败 | 当前 Python 版本缺少缓存轮子 | 检查已有环境与包支持的版本，选兼容环境；不据此认定加速不可用 |
| 无 ffmpeg / ffprobe | 工具缺失或未进入 PATH | 查已有可执行路径，使用脚本的路径参数；确实缺失时按当前环境规则安装 |
| 已抽帧但没读图 | 只完成了文件生成 | 实际打开联系表和完整帧；没有视觉能力时说明限制 |
| 字幕看不清 / 漏了动作 | 联系表太小或采样太疏 | 打开全帧，缩短间隔，指定时间；不根据模糊截图猜数字 |
| ASR 英文名错、静音处出现句子 | 识别错误或幻觉 | 用画面、上下文及对应音频核对；原始稿不改，清洗稿标注不确定 |
| 私密 / 登录 / 删除 / 验证码 | 访问条件限制 | 使用用户已有授权能力或本地材料；不绕过访问控制 |

每次换路径都保持同一内容 ID。失败后保留已获得的材料和错误分类；不要让重复尝试覆盖它们。先处理独立可完成部分，再说明仍缺什么。

不要把“打不开网页”“下载了文件”“生成了截图”“转写了音频”“事实已核实”混为同一状态。最后说明实际完成范围及具体缺口。
